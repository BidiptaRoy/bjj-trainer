#Nogi BJJ Trainer is a full-stack web application built to help Brazilian Jiu-Jitsu practitioners learn, drill, and test their knowledge of no-gi techniques in a structured and interactive way.

#The application organizes 19+ techniques across 6 categories, each with instructional content and interactive quizzes to reinforce learning. Users can test their understanding through multiple-choice quizzes, submit answers in real time, and view their quiz results with the option to retake

Frontend: React, Tailwind CSS
Backend: Node.js, Express
Database for comments/profile: MongoDB atlas
